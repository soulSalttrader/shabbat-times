# Classify changes and update 02-split-diff.sh

You are helping prepare a pull request in this repository.

Read these two files, generated by `@./scripts/01-gather-context.sh`:
- `@.pr-context/diff-stat-all.txt` — diffstat (paths + lines changed) for this branch vs. the base branch
- `@.pr-context/commits.txt` — commit log for this branch

## Task

Classify the changed paths into two groups:

- **MAIN**: paths that represent the core feature or logic change of this PR
- **MINOR**: paths that are likely mechanical/incidental — renames, formatting, dependency bumps, generated files, small unrelated touch-ups, ktlint fixes, unrelated config changes

## Rules

- Use commit messages as the strongest signal of intent — they tell you *why* something changed, which line/file counts alone cannot.
- A path with many changed lines is not automatically MAIN — check whether the commits suggest it's a rename, move, or formatting-only change.
- A path with few changed lines is not automatically MINOR — a small but meaningful logic/config change can matter more than a large mechanical diff.
- Group by directory/package where possible instead of listing every file.
- Test paths (`**/androidTest/**`, `**/test/**`, `**/*Test.kt`) are handled separately later — do not include them in either MAIN or MINOR.
- If you are unsure whether something is MAIN or MINOR, say so explicitly in a short note rather than guessing silently.

## Action

Edit `@./scripts/02-split-diff.sh`:
- Replace the contents of the `MAIN_PATHS` array with your classified MAIN paths, as glob patterns matching the existing style in the file (e.g. `'**/times/settings/**'`).
- Do not modify `TEST_PATHS` or anything else in the script.
- Do not run the script yourself — I will review the paths and run it.
